welcome.lua 启动页

打包器在生成 APK 时读取工程根目录的 welcome.lua，生成启动页窗口背景 welcome.xml。没有这个文件时，启动页保持基础包里的纯色背景和居中 icon.png。

启动页在解压资源之前显示，所以它不能是 Lua 布局，也不能在运行时改。它只在打包结果里生效，不会改变 IDE 自己的启动页。

打包器会在一个去掉文件、进程和 Java 桥的 Lua 环境里执行它，并使用返回的表。可以用 string、table 和 math 计算字段，但不能使用 io、os、require 或 loadfile。

字段

  • background：#RRGGBB 或 #AARRGGBB。缺省是 ?colorSurface。
  • icon：工程根目录里的图片文件名，缺省 icon.png。工程里没有 icon.png 时，继续使用基础包里的图标。false 表示不显示图标。
  • icon_size：图标边长，只能是 dp，例如 160dp。
  • gravity：图标位置，例如 center 或 center|bottom。
  • image：整页图片。设置后铺满启动页，并忽略 icon。
  • text：最多 80 个字符、6 行。打包时用系统字体画成图片，因为窗口背景不能放文字控件。尺寸按 4 倍密度固定，不跟随打包手机的字体缩放。
  • text_size：例如 24sp，缺省 24sp。
  • text_color：#RRGGBB 或 #AARRGGBB，缺省白色。
  • text_gravity：文字位置。旁边还有图标或整页图时，缺省是 center|bottom。

图片必须位于工程根目录，扩展名是 png、webp、jpg 或 jpeg。文件名去掉扩展名后必须是小写资源名，例如 welcome.png。不能写路径。自定义图片最多 4 张，文字层最多 4 层。打包前要先安装包含这些改动的 NeLuaJ+，因为基础包里要有预留的图片资源。

示例

return {
  background = "#121212",
  icon = "icon.png",
  icon_size = "160dp",
  gravity = "center",
}

return {
  background = "#FF101418",
  image = "welcome.png",
}

多层

需要渐变、圆形或几张图叠在一起时，用 layers 数组代替上面的字段。每一层只能有一种内容：纯色、渐变、图标或图片。

local color = string.format("#%06X", 0x112233)
return {
  layers = {
    { color = color },
    {
      shape = "oval",
      gradient_start = "#00112233",
      gradient_end = "#FF112233",
      gradient_angle = "90",
      size = "240dp",
    },
    { icon = "icon.png", size = "72dp", gravity = "center|bottom", inset = "24dp" },
  },
}

层字段还有 corners、text、text_size 和 text_color。文字层同样会画成图片。渐变角度只能是 45 的倍数。layers 不能和顶层的 background、icon、image、text 同时写。

限制

  • 生成结果只有 layer-list、item、bitmap、shape、solid 和 color。
  • 不能放文字、按钮或任意布局。
  • 未知字段、错误颜色、像素单位或缺失图片会让这次打包失败。
