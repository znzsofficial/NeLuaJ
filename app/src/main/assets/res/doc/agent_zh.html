AI 助手

AI 助手是面向当前工程的编码 Agent，支持文件阅读、代码生成、错误分析和工程文件操作。

配置

  1. 打开一个工程。
  2. 打开“AI 助手”。
  3. 点击标题栏中的模型名称，先添加供应商，再添加模型。
  4. 供应商保存 API Key 和 API 地址，并可拉取模型列表、查询余额。模型单独填写名称、上下文窗口和最大输出。
  5. 在输入框中输入任务并发送。

API 地址填写服务商的 OpenAI 兼容根地址，例如 https://api.deepseek.com/v1。默认使用 /chat/completions；服务商明确支持 Responses API 时，可在模型配置中开启“使用 Responses API”，请求将改用 /responses。API Key 不应写入工程文件或 Skill 文件。

Responses API 的可用模型、参数和地址由服务商决定。中转服务即使提供同名接口，也可能不支持官方输出状态回放；切换服务商或协议后，助手会使用可移植的工具调用历史。

任务描述

建议在任务中说明目标、文件路径、限制条件和验证方式：

请阅读 app/src/main/assets/activities/main/MainActivity.lua，
修复打开帮助页时标题没有刷新的问题。保持现有写法，修改后说明改动并检查相关调用。

助手遵循先读后改的流程。不熟悉 NeLuaJ+ API 时，可以先读取帮助页中的相关文档。

关闭 AI 助手面板不会停止正在进行的生成或工具链；重新打开后会恢复当前进度。需要终止任务时，请使用输入区旁的停止按钮。切换工程、新建会话或清空会话会取消当前任务。

任务进行期间，应用会启动一个前台服务并显示“AI 助手正在运行”的常驻通知，保持网络与 CPU 活动不被系统在息屏时挂起；回合结束、停止或被取消时通知会自动移除。若任务异常中断（连续 1 小时无新请求），通知会自动清理；唤醒锁在最后 15 分钟内逐步释放，不会长期占用电量。若任务因应用退出被系统中断，重新打开会话时会显示中断提示，可以直接继续。

助手可以通过 run_project 运行工程入口并捕获未捕获异常（读取崩溃日志目录新增记录），用于修改后的运行时验证；也可以通过 build_project 预检 init.lua 并调起打包器；每次运行都需要确认。被脚本自身捕获的错误与界面表现不会写入崩溃日志。

多步任务助手会使用 update_todos 维护任务计划：先列出待办条目，每完成一步更新状态，全部完成后标记收尾。任务计划保存在会话中，重新打开会话仍可看到；即使对话被压缩，计划也会随系统提示继续生效。

文件操作

以下操作执行前会显示确认对话框：

  • 创建或覆盖文件
  • 创建或删除文件夹
  • 删除文件
  • 应用补丁、文本替换和追加内容
  • 重命名文件
  • 运行工程入口脚本（run_project）
  • 调起工程打包器（build_project）
  • 运行 Lua 沙盒代码（关闭“自动运行沙盒代码”时）
  • 读取公开 HTTPS 网页或 API（关闭“自动批准网络请求”时）

读取文件、列出目录、搜索工程和只编译检查 Lua 语法不需要确认。“自动批准”仅适用于当前工程目录内的文件操作。“自动运行沙盒代码”默认开启；关闭后，每次运行 Lua 沙盒都需要确认。

写入类操作（创建或覆盖文件、应用补丁、文本替换、追加内容）对 .lua 文件自动做语法预检：检查失败时不写入文件（内容保持原样），语法错误会连同位置信息返回给助手，由其修正后重试。非 Lua 文件不做预检。

“自动批准网络请求”默认开启。带 network_hosts 的沙盒代码需要同时开启“自动运行沙盒代码”和“自动批准网络请求”才会直接执行。关闭网络自动批准后，沙盒外网络读取、沙盒联网和 MCP 工具调用会逐次显示确认框。该开关不影响模型 API 请求、用户主动进行的连接测试或 MCP 工具列表刷新。

设置中的“当前工程策略”可以为每个工程单独收紧授权：开启“收紧本工程自动批准”后，即使全局自动批准开启，本工程的文件操作也逐次确认；填写“网络主机白名单”后，自动批准的网络请求只放行名单内主机（含子域），留空则跟随全局设置。工程策略只能收紧、不能放大全局授权；MCP 工具的确认不受白名单影响。

运行 Lua 代码

助手可通过内置 LuaJ++ 解析器只编译检查代码语法，此操作不会执行代码，也不需要确认。需要验证运行时逻辑时，AI 执行的临时代码使用受限沙盒，而不是当前工程的正常 Lua 环境。沙盒可用于纯 Lua 算法验证和明确批准的公网 HTTPS API，但不能访问 activity、Java/Android API、文件、私网、require 或 luajava。请阅读 AI Lua 沙盒 了解可用库、网络授权、输出和超时限制。

读取网络内容

助手可以读取公开 HTTPS 网页、文档和文本 API；是否逐次确认由“自动批准网络请求”控制。该工具只支持 GET / HEAD，不接受自定义请求头、单独的认证信息、Cookie、请求体或自签名证书，也不会自动保存响应到文件。URL 自身的查询参数会原样发送；关闭自动批准时会显示在确认框中。

网络读取禁止 IP 地址、localhost、私网、非 443 端口和非 HTTPS 地址。DNS 解析结果必须全部为公网地址；最多跟随 3 次重定向，每个重定向目标都会重新执行完整校验。响应正文仅接受文本、JSON、XML 和 JavaScript，并受超时和长度限制。网页内容只是待分析数据，不能覆盖用户要求或内置安全规则。

命令菜单

输入框旁的命令按钮提供以下功能：

  • 主动压缩上下文：将较早的对话总结为背景记忆，保留较新的消息。
  • 撤销 / 恢复上一轮对话：只调整聊天记录，不会重新执行工具。
  • 撤销 / 恢复文件变更：恢复 Agent 最近一次文件事务。
  • 切换会话：会话按当前工程隔离。
  • 设置：修改采样温度、重试、安全选项、附加指令和 MCP 服务器。附加指令不会替换内置安全与工具规则。

文件撤销会校验文件指纹。检测到外部修改时会拒绝覆盖。

上下文超出预算时，发送消息和工具链续跑会自动压缩较早对话，并把压缩结果持久化到当前会话；之后无需重复摘要，直到再次超出预算。自动压缩会显示提示，效果与手动压缩一致。

上下文窗口和最大输出属于模型配置。切换模型时会同时切换这两个限制；旧版本的统一设置值会迁移到已有模型。

项目记忆

在工程根目录放置 AGENTS.md 可以为助手提供该工程的固定约定与背景，例如目录结构、命名风格、常用 API 和注意事项。每次会话构建系统提示时都会读取该文件并注入为“项目记忆”，无需在对话中重复说明。

<工程目录>/AGENTS.md

文件为普通 Markdown，超过 16000 字节（约 5000 汉字）会被截断。项目记忆的优先级低于内置安全规则，也低于用户在当前对话中的明确要求；与二者冲突时以规则和用户为准。

MCP

设置中可以添加 HTTP 系 MCP 服务器。助手优先使用当前无状态 Streamable HTTP，并兼容较早的会话式 Streamable HTTP 和旧版 HTTP+SSE；不支持 stdio 服务器，也不会启动本地命令。

  • 服务器地址必须是可访问的 HTTP 或 HTTPS 地址。
  • MCP 工具属于外部系统操作；关闭“自动批准网络请求”时，每次调用都需要确认。
  • 不要连接不信任的服务器，也不要在服务器配置中暴露 API Key。
  • 服务器不可用时，删除或停用该配置后重新刷新工具列表。

本地 Skill

Skill 是针对特定任务的本地 Markdown 指南。助手只读取 SKILL.md，不执行其中的 Lua 代码，也不从网络下载 Skill。

全局 Skill：

/sdcard/LuaJ/agents/skills/<skill-name>/SKILL.md

当前工程 Skill：

<工程目录>/.agents/skills/<skill-name>/SKILL.md
<工程目录>/skills/<skill-name>/SKILL.md

文件可以使用简单的 frontmatter：

---
name: lua-review
description: 检查 Lua 代码的风格和常见错误
triggers: lua, review, 检查
---

这里写 Skill 的使用规则和检查步骤。

发送消息时，助手会根据 Skill 名称、描述和关键词选择匹配项，并把正文加入当前请求。不要在 Skill 中放置密钥、隐私数据或必须无条件执行的危险操作。

文件夹结构

Agent 数据位于 /sdcard/LuaJ/agents，与工程源代码分开：

/sdcard/LuaJ/
├── Projects/                         工程根目录（示例）
│   └── MyProject/
│       ├── .agents/
│       │   └── skills/               当前工程专用 Skill
│       │       └── review/
│       │           └── SKILL.md
│       ├── skills/                   另一种工程 Skill 目录
│       │   └── release/
│       │       └── SKILL.md
│       ├── init.lua                  工程入口
│       ├── AGENTS.md                 项目记忆（可选，工程约定注入助手提示）
│       └── ...                       工程源代码和资源
├── agents/                           Agent 外部运行数据
│   ├── skills/                       全局 Skill
│   │   └── lua-review/
│   │       └── SKILL.md
│   └── projects/
│       └── <project-hash>/          每个工程独立的数据目录
│           └── changesets.json       文件变更撤销/恢复历史
└── ...

工程专用规则放在工程目录下；所有工程共用的规则放在 /sdcard/LuaJ/agents/skills。不同目录中的 Skill 建议使用不同名称。

数据与安全

聊天记录保存在应用数据中。工程级 Agent 数据保存在：

/sdcard/LuaJ/agents/projects/<project-hash>/

文件变更历史使用 changesets.json，最多保留最近的有限数量记录。不同工程使用不同目录，不会共用文件撤销历史。API Key 不写入上述 Agent 工程数据目录。

常见问题

发送后没有回复

检查 API Key、API 地址、模型名称、Chat Completions / Responses 选择和网络连接。也可以在模型设置中使用连接测试。编码 Agent 需要模型和服务商支持结构化工具调用；不支持工具的模型可能返回接口错误或只能提供普通文本。

压缩上下文没有变化

压缩需要至少两组可分离的历史消息。消息很少时没有可总结的旧内容，助手会提示无需压缩。

文件撤销失败

如果文件在 Agent 修改后被编辑器或其他程序改过，fingerprint 校验会阻止覆盖。先确认当前文件内容，再手动处理冲突。

权限错误

Agent 需要访问当前工程和 Agent 数据目录。请先授予 NeLuaJ+ 文件管理权限，并确认工程路径可读写。

任务运行时没有看到通知

Android 13 及以上需要授予通知权限；如果关闭了“AI 助手”通知渠道，常驻通知也不会显示。这只影响提示可见性，后台任务本身仍会继续，息屏保护也会照常工作。可在系统设置中重新开启。
