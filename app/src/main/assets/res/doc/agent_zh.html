AI 助手

AI 助手是面向当前工程的编码 Agent，支持文件阅读、代码生成、错误分析和工程文件操作。

配置

  1. 打开一个工程。
  2. 打开“AI 助手”。
  3. 点击标题栏中的模型名称，添加模型配置。
  4. 填写 API Key、API 地址和模型名称，然后选择模型。
  5. 在输入框中输入任务并发送。

API 地址填写服务商的 OpenAI 兼容根地址，例如 https://api.deepseek.com/v1。请求接口为该地址下的 /chat/completions。API Key 不应写入工程文件或 Skill 文件。

任务描述

建议在任务中说明目标、文件路径、限制条件和验证方式：

请阅读 app/src/main/assets/activities/main/MainActivity.lua，
修复打开帮助页时标题没有刷新的问题。保持现有写法，修改后说明改动并检查相关调用。

助手遵循先读后改的流程。不熟悉 NeLuaJ+ API 时，可以先读取帮助页中的相关文档。

文件操作

以下操作执行前会显示确认对话框：

  • 创建或覆盖文件
  • 创建或删除文件夹
  • 删除文件
  • 应用补丁、文本替换和追加内容
  • 重命名文件
  • 运行 Lua 代码

读取文件、列出目录和搜索工程不需要确认。“自动批准”仅适用于当前工程目录内的文件操作。MCP 工具和 Lua 代码执行仍需要确认。

运行 Lua 代码

AI 执行临时代码时使用受限沙盒，而不是当前工程的正常 Lua 环境。沙盒可用于纯 Lua 语法和算法验证，但不能访问 activity、Java/Android API、文件、网络、require 或 luajava。请阅读 AI Lua 沙盒 了解可用库、输出和超时限制。

命令菜单

输入框旁的命令按钮提供以下功能：

  • 主动压缩上下文：将较早的对话总结为背景记忆，保留较新的消息。
  • 撤销 / 恢复上一轮对话：只调整聊天记录，不会重新执行工具。
  • 撤销 / 恢复文件变更：恢复 Agent 最近一次文件事务。
  • 切换会话：会话按当前工程隔离。
  • 设置：修改 API、上下文长度、最大输出和自动批准等选项。

文件撤销会校验文件指纹。检测到外部修改时会拒绝覆盖。

MCP

设置中可以添加使用 Streamable HTTP 的 MCP 服务器。连接成功后，助手会发现并调用服务器工具。

  • 服务器地址必须是可访问的 HTTP 或 HTTPS 地址。
  • MCP 工具属于外部系统操作，每次调用都需要确认。
  • 不要连接不信任的服务器，也不要在服务器配置中暴露 API Key。
  • 服务器不可用时，删除或停用该配置后重新刷新工具列表。

本地 Skill

Skill 是针对特定任务的本地 Markdown 指南。助手只读取 SKILL.md，不执行其中的 Lua 代码，也不从网络下载 Skill。

全局 Skill：

/sdcard/LuaJ/agents/skills/<skill-name>/SKILL.md

当前工程 Skill：

<工程目录>/.agents/skills/<skill-name>/SKILL.md
<工程目录>/skills/<skill-name>/SKILL.md

文件可以使用简单的 frontmatter：

---
name: lua-review
description: 检查 Lua 代码的风格和常见错误
triggers: lua, review, 检查
---

这里写 Skill 的使用规则和检查步骤。

发送消息时，助手会根据 Skill 名称、描述和关键词选择匹配项，并把正文加入当前请求。不要在 Skill 中放置密钥、隐私数据或必须无条件执行的危险操作。

文件夹结构

Agent 数据位于 /sdcard/LuaJ/agents，与工程源代码分开：

/sdcard/LuaJ/
├── Projects/                         工程根目录（示例）
│   └── MyProject/
│       ├── .agents/
│       │   └── skills/               当前工程专用 Skill
│       │       └── review/
│       │           └── SKILL.md
│       ├── skills/                   另一种工程 Skill 目录
│       │   └── release/
│       │       └── SKILL.md
│       ├── init.lua                  工程入口
│       └── ...                       工程源代码和资源
├── agents/                           Agent 外部运行数据
│   ├── skills/                       全局 Skill
│   │   └── lua-review/
│   │       └── SKILL.md
│   └── projects/
│       └── <project-hash>/          每个工程独立的数据目录
│           └── changesets.json       文件变更撤销/恢复历史
└── ...

工程专用规则放在工程目录下；所有工程共用的规则放在 /sdcard/LuaJ/agents/skills。不同目录中的 Skill 建议使用不同名称。

数据与安全

聊天记录保存在应用数据中。工程级 Agent 数据保存在：

/sdcard/LuaJ/agents/projects/<project-hash>/

文件变更历史使用 changesets.json，最多保留最近的有限数量记录。不同工程使用不同目录，不会共用文件撤销历史。API Key 不写入上述 Agent 工程数据目录。

常见问题

发送后没有回复

检查 API Key、API 地址、模型名称和网络连接。也可以在模型设置中使用连接测试。部分模型不支持工具调用，助手会自动以纯文本模式请求。

压缩上下文没有变化

压缩需要至少两组可分离的历史消息。消息很少时没有可总结的旧内容，助手会提示无需压缩。

文件撤销失败

如果文件在 Agent 修改后被编辑器或其他程序改过，fingerprint 校验会阻止覆盖。先确认当前文件内容，再手动处理冲突。

权限错误

Agent 需要访问当前工程和 Agent 数据目录。请先授予 NeLuaJ+ 文件管理权限，并确认工程路径可读写。
