AI Lua Sandbox

When the AI Assistant uses “Run Lua code”, the code runs in a separate restricted Lua environment. It is for checking small, pure-Lua calculations or string processing. It is not the runtime for project scripts, Activity scripts, or modules.

Appropriate Uses

  • Check Lua syntax and small algorithms.
  • Test pure Lua logic using table, string, math, utf8, coroutines, and bit32.
  • Inspect calculation results with print(...).

Available Environment

The sandbox provides basic Lua functions plus coroutine, string, table, math, utf8, and bit32.

local total = 0
for i = 1, 10 do
  total = total + i
end
print(total) -- 55

Unavailable Capabilities

The sandbox intentionally has no Java, Android, file, network, or process entry points. These names are unavailable:

luajava  import  require  package  debug
io  os  dofile  loadfile  collectgarbage

You cannot access activity, call Android APIs, read project files, load modules, make HTTP requests, or execute shell commands there. For those tasks, edit and test the relevant Lua file in the normal project runtime instead.

Output and Limits

  • UTF-8 source is limited to 128 KiB.
  • print output and runtime errors are returned to the AI. Output is limited to 64 KiB and is marked when truncated.
  • Execution is time-limited. A timed-out run fails; use smaller inputs or a more efficient algorithm.
  • An infinite loop or blocked run does not remain in the app process. The sandbox execution process is ended after timeout.

Troubleshooting

Why are require and luajava nil?

This is intentional. Temporary AI code cannot access the project, device, or Java bridge. Test an extracted pure function, or run the code from the normal project environment.

Why is there no output?

Only print output and runtime errors are captured. Chunk return values are not shown automatically, so use print(value).

Why did execution time out?

Check for an infinite loop, recursion without a terminating condition, or overly large input. Split the work and avoid large enumerations in the sandbox.
