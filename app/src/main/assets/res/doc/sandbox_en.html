AI Lua Sandbox

When the AI Assistant uses “Run Lua code”, the code runs in a separate restricted Lua environment. It is for checking small, pure-Lua calculations or string processing. It is not the runtime for project scripts, Activity scripts, or modules.

Appropriate Uses

  • Check Lua syntax and small algorithms.
  • Test pure Lua logic using table, string, math, utf8, coroutines, and bit32.
  • Validate JSON, Base64, Hex, URL encoding, and SHA-256 digests.
  • Test a public HTTPS API after explicitly approving its exact host.
  • Inspect results with print(...) or chunk return values.

Available Environment

The sandbox provides basic Lua functions plus coroutine, string, table, math, utf8, and bit32.

local total = 0
for i = 1, 10 do
  total = total + i
end
print(total) -- 55

Safe Utilities

  • json.encode(value) / json.decode(text): JSON encoding and decoding; use json.null for null and json.array() to create or mark an empty array.
  • codec.base64_encode / base64_decode: Base64 encoding and decoding.
  • codec.hex_encode / hex_decode: Hex encoding and decoding.
  • codec.url_encode / url_decode: UTF-8 URL form encoding.
  • hash.sha256(text): lowercase hexadecimal SHA-256.
  • inspect(value): stable table formatting with cycle protection.
  • assert_equal(actual, expected, message): recursive equality with a readable failure diff.
  • http.request(url, options): restricted synchronous HTTPS request. The exact host must also be listed in the tool's network_hosts argument and approved by the user.
local value = json.decode('{"items":[1,2,3]}')
assert_equal(value.items, {1, 2, 3})
return hash.sha256(json.encode(value))

Restricted HTTPS

local response = http.request("https://api.example.com/items", {
  method = "POST",
  headers = { ["Content-Type"] = "application/json" },
  body = json.encode({ query = "Lua" }),
  timeout = 4000,
})
assert_equal(response.status, 200)
return json.decode(response.body)

The corresponding run_lua call must include network_hosts = {"api.example.com"}. Authorization is exact-host only: approving example.com does not approve its subdomains.

The response table contains ok, status, message, url, headers, header_values (arrays preserving repeated headers), and binary-safe body.

Unavailable Capabilities

The sandbox intentionally has no Java, Android, file, unrestricted network, or process entry points. These names are unavailable:

luajava  import  require  package  debug
io  os  dofile  loadfile  collectgarbage

You cannot access activity, call Android APIs, read project files, load modules, open arbitrary sockets, or execute shell commands there. Network access is limited to http.request and user-approved public HTTPS hosts. For broader capabilities, edit and test the relevant Lua file in the normal project runtime instead.

Output and Limits

  • UTF-8 source is limited to 128 KiB.
  • print output, chunk return values, and runtime errors are returned to the AI. Output is limited to 64 KiB and is marked when truncated.
  • JSON, codec, and digest inputs or results are limited to 1 MiB per operation. JSON is limited to 10,000 nodes and 64 nesting levels.
  • HTTP is limited to HTTPS port 443, eight exact approved hosts, and four requests per run. Redirects, proxies, URL credentials, IP literals, localhost, private/link-local addresses, and non-public DNS results are rejected.
  • HTTP request bodies are limited to 256 KiB, response bodies to 512 KiB, and per-request timeouts to 1–6 seconds. Cookies and application credentials are never added automatically.
  • Execution is time-limited. A timed-out run fails; use smaller inputs or a more efficient algorithm.
  • An infinite loop or blocked run does not remain in the app process. The sandbox execution process is ended after timeout.

Troubleshooting

Why are require and luajava nil?

This is intentional. Temporary AI code cannot access the project, device, or Java bridge. Test an extracted pure function, or run the code from the normal project environment.

Why is there no output?

Both print output and Lua chunk return values are shown. Ordinary values returned inside a function are not shown unless the chunk returns or prints them.

Why did execution time out?

Check for an infinite loop, recursion without a terminating condition, or overly large input. Split the work and avoid large enumerations in the sandbox.
