LuaFileUtil

LuaFileUtil 是 IDE 自己的文件工具（com.nekolaska.io.LuaFileUtil）。 启动后已是全局变量。它和 file 模块不是一回事：file 是脚本运行时的轻量接口，这里的方法给工程管理、代理和编辑器用。

路径请传绝对路径。读写使用 UTF-8。底层是 java.nio.file，需要 Android 8（API 26）及以上。

-- 一般直接用全局
local text = LuaFileUtil.read("/sdcard/LuaJ/Projects/demo/main.lua")

-- 不在 IDE 启动环境里时再自己取
local LuaFileUtil = luajava.kotlinObject("com.nekolaska.io.LuaFileUtil")

读和写

read(path)

读出整个文件。失败或不存在时返回空字符串 ""，不抛错。因此空文件和读失败无法从返回值区分，调用方需要自己看文件是否存在、长度是否大于 0。

write(path, content)

覆盖已存在的文件。文件不存在返回 false，不会创建。成功返回 true。

writeOrCreate(path, content)

写入文件。不存在则连同父目录一起创建。失败返回 false。

create(path, content)

创建父目录后写入。失败会抛错，而不是返回 false。新代码优先用 writeOrCreate。

删除

remove(path)

只删除一个文件或空目录。非空目录会失败并返回 false。

removeTree(path)

递归删除文件或目录。路径本来就不存在也返回 true。列举子项失败，或其中有一个删不掉，返回 false。这时可能已经删掉一部分，父目录还在。

if LuaFileUtil.removeTree(projectDir) and not File(projectDir).exists() then
  print("已删除")
end

复制和移动

copyFile(src, dest)

复制单个文件，并创建目标的父目录。源不是普通文件、或源和目标是同一路径时返回 false。目标已存在则覆盖。

copyTree(src, dest)

递归复制文件或目录，不删除源。目标如果就是源，或者落在源目录里面，直接返回 false，避免复制到自己内部时无限递归。比较按路径段进行，/proj 不会被当成 /proj2 的前缀。

rename(oldPath, newPath)

移动或改名。目标已存在时失败，返回 false。不会自动创建缺失的中间目录。

moveDirectory(src, dest)

先 copyTree，成功后再 removeTree 删源。不是原子操作：复制成功但删除失败时，源和目标会同时存在。

目录

checkDirectory(path)

目录不存在则创建（含父目录）。已存在则什么都不做。无返回值。

isEmpty(path)

是空目录时返回 true。不是目录、或不存在，返回 false。

lastModified(path)

最近修改时间，单位毫秒。不存在返回 0。

listMeta(path)

列出目录的直接子项，返回数组。每一项是表：name、isDir、mtime（毫秒）、size（字节）。不是目录时返回空表。某个条目读不到属性时会跳过，不影响其余条目。

for _, entry in ipairs(LuaFileUtil.listMeta(dir)) do
  print(entry.name, entry.isDir, entry.mtime, entry.size)
end

listDirs(path)

只返回子目录名，按最近修改时间从新到旧排列。

listTree(path, filter, maxItems, maxDepth)

递归列出相对路径。目录名以 / 结尾，每一层按名称排序。filter 为空或 nil 时不过滤，否则保留路径或文件名包含该子串的条目。会跳过 .git、build、node_modules 等版本控制和构建目录，不再往下走。达到 maxItems 或 maxDepth 后停止。

searchInFiles(root, pattern, ignoreCase, maxResults, maxFileKB)

在目录树里做子串搜索，不是正则。返回表：

  • matches：数组，每项形如 绝对路径:行号: 该行内容
  • scanned：实际打开过的文件数

跳过版本控制与构建目录、空文件、超过 maxFileKB 的文件，以及内容里含 NUL 的二进制文件。最多扫描 2000 个文件、8 层目录。

压缩

compress(srcFolder, destZipDir, fileName)

把目录打成 zip，仍使用运行时的 LuaUtil.zip，以保持备份包格式不变。

extract

extract(zipPath, outPath) 在后台线程解压，没有进度。extract(file, targetDir, callback) 带进度回调，参数是已处理量和总大小。zip 无效或目标目录创建失败时抛错。

和 file 模块怎么选

  • 脚本里读一点文本、存一个结果：用 file.readall / file.save。
  • 要复制目录、递归删除、列元数据或在工程里搜索：用 LuaFileUtil。
  • 不要用 LuaUtil.rmDir / copyFile / copyDir。那些是旧运行时接口，新代码走上面的方法。
