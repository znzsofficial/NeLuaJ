LuaFileUtil

com.nekolaska.io.LuaFileUtil 是一个 Kotlin object，提供文件与目录操作。 用 luajava.kotlinObject 取得，也可以读它的 INSTANCE 字段。 

local LuaFileUtil = luajava.kotlinObject("com.nekolaska.io.LuaFileUtil")
-- 等价写法
local LuaFileUtil = luajava.bindClass("com.nekolaska.io.LuaFileUtil").INSTANCE

路径使用绝对路径。文本按 UTF-8 读写。成员调用用点号，不要用冒号。

它和 file 模块可以同时用。file 适合读一点文本、存一个结果；需要复制目录、递归删除、列出元数据或在目录树里搜索时用这里的方法。

读和写

read(path)

读出整个文件，返回字符串。失败或不存在时返回 ""，不抛错。空文件也是 ""，二者无法从返回值区分。需要区分时先看文件是否存在、长度是否大于 0。

local text = LuaFileUtil.read("/sdcard/demo/main.lua")

write(path, content)

覆盖已经存在的文件，成功返回 true。文件不存在返回 false，不会创建。

writeOrCreate(path, content)

写入文件。文件或父目录不存在时会创建。失败返回 false。

LuaFileUtil.writeOrCreate("/sdcard/demo/out/note.txt", "hello")

create(path, content)

创建父目录后写入。失败会抛错，而不是返回 false。新代码优先用 writeOrCreate。

删除

remove(path)

删除一个文件，或一个空目录。非空目录返回 false。

removeTree(path)

递归删除文件或目录。路径本来就不存在也返回 true。子项列举失败，或其中有一个删不掉，返回 false。这时可能已经删掉一部分，目录本身还在。

local File = luajava.bindClass("java.io.File")
local path = "/sdcard/demo/build"
if LuaFileUtil.removeTree(path) and not File(path).exists() then
  print("已删除")
end

复制和移动

copyFile(src, dest)

复制单个文件，并创建目标的父目录。源不是普通文件，或源和目标是同一路径时，返回 false。目标已存在则覆盖。

copyTree(src, dest)

递归复制文件或目录，不删除源。目标就是源，或者落在源目录里面时，直接返回 false，避免复制进自己导致无限递归。已存在的路径会先展开符号链接再比较，所以 /sdcard 和 /storage/emulated/0 指的是同一处时也会被认出来。/proj 不会被当成 /proj2 的前缀。

LuaFileUtil.copyTree("/sdcard/demo/res", "/sdcard/demo/res_backup")

rename(oldPath, newPath)

移动或改名。目标已存在时失败，返回 false。不会自动创建缺失的中间目录。

moveDirectory(src, dest)

先 copyTree，成功后再 removeTree 删除源。这不是一次原子操作：复制成功但删除失败时，源和目标会同时存在。

目录

checkDirectory(path)

目录不存在则创建，包括缺失的父目录。已经存在则什么都不做。没有返回值。

isEmpty(path)

空目录返回 true。不是目录、不存在，或目录读不出来，返回 false。

lastModified(path)

最近修改时间，单位毫秒。不存在返回 0。

listMeta(path)

列出目录的直接子项。返回数组，每一项是表：

  • name 文件名
  • isDir 是否目录
  • mtime 修改时间，毫秒
  • size 字节数

路径不是目录时返回空表。某一个条目读不到属性时会跳过，其余条目仍然返回。

for _, entry in ipairs(LuaFileUtil.listMeta("/sdcard/demo")) do
  print(entry.name, entry.isDir, entry.size)
end

listDirs(path)

只返回子目录名，按最近修改从新到旧排列。

listTree(path, filter, maxItems, maxDepth)

递归列出相对路径。目录名以 / 结尾，每一层按名称排序。filter 为 nil 或空字符串时不过滤；否则只保留路径或文件名包含该子串的条目。

这些目录名不会再往下走：.git、.svn、.hg、.idea、.gradle、build、dist、target、node_modules、bin、obj、.cxx。达到 maxItems 或 maxDepth 后停止。

searchInFiles(root, pattern, ignoreCase, maxResults, maxFileKB)

在目录树里做子串搜索，不是正则。返回一个表：

  • matches 数组，每项形如 绝对路径:行号: 该行内容
  • scanned 实际打开过的文件数

会跳过上面列出的版本控制与构建目录、空文件、超过 maxFileKB 的文件，以及内容中含 NUL 字节的文件。另外最多扫描 2000 个文件、深入 8 层。

local found = LuaFileUtil.searchInFiles("/sdcard/demo", "TODO", true, 50, 256)
for _, line in ipairs(found.matches) do
  print(line)
end
print("scanned", found.scanned)

压缩

compress(srcFolder, destZipDir, fileName)

把目录打成 zip，写到 destZipDir 下，文件名为 fileName。没有返回值，失败时抛错。

extract(zipPath, outPath)

在后台线程解压，调用后立即返回，没有进度，也没有完成回调。

extract(zipFile, targetDir, callback)

解压 java.io.File。进度回调收到两个数：已处理量和总大小（zip 文件的字节数，不是解压后的大小）。zip 不是有效文件，或目标目录创建失败时抛错。
