file 模块

file 提供常用文件与目录操作。路径支持绝对路径，也支持相对于工程 / 工作目录的路径（与当前运行上下文有关）。

API

file.readall(path)

local text = file.readall("main.lua")
local text2 = file.readall("/sdcard/test.lua")

读取整个文件为字符串。

file.save(path, content)

local ok, err = file.save("out.txt", "print('hello')")
if not ok then print(err) end

写入文件并按需创建父目录。先写同目录临时文件，再替换目标，避免直接截断原文件。成功返回 true；失败返回 false 和具体错误信息（如权限或存储错误）。

file.exists(path)

if file.exists("init.lua") then
  print("exists")
end

file.type(path)

print(file.type(this.getLuaPath("main.lua"))) -- "file"，不存在时 nil

普通文件返回 "file"，目录返回 "dir"，不存在返回 nil。权限错误、非目录父路径以及符号链接等不支持的类型会抛出错误，不会伪装成路径不存在。

二进制快照与不覆盖重命名

local encoded, err = file.readbinary(path)
if encoded then
  local ok, writeErr = file.savebinary(backupPath, encoded)
end
local moved, moveErr = file.renameexclusive(sourcePath, targetPath)

readbinary 返回原始字节的 Base64 字符串，失败返回 nil 和错误；savebinary 解码后通过临时文件替换写入，失败返回 false 和错误。renameexclusive 拒绝已存在的目标，成功返回 true，失败返回 false 和错误。

file.info(path)

local info = file.info("main.lua")
-- 常见字段：name、path、size、isDirectory 等（以实际返回表为准）

file.list(path)

local names = file.list("/sdcard")
for i, name in ipairs(names) do
  print(i, name)
end

列出目录下名称；内部通过表转换实现，大目录可能偏慢。

file.mkdir(path)

file.mkdir("/sdcard/NeLuaJ/demo")

创建目录及其缺失的父目录。

完整示例

local path = this.getLuaPath("cache/note.txt")
file.mkdir(this.getLuaPath("cache"))
file.save(path, "hello file module")
if file.exists(path) then
  print(file.readall(path))
  print(file.type(path), file.info(path))
end
