Java 互操作

本文汇总 NeLuaJ+ / LuaJ++ 中与 Java 交互的常用方式。luajava.bindClass() 提供类包装，Java/Kotlin 成员以 对象.方法(...) 形式调用。

调用特点

  • Java 数组、List、Map 的下标遵循 Java 规则，从 0 开始；Lua table 的数组部分仍从 1 开始。
  • Java/Kotlin 方法使用点调用，例如 view.setText("hello")。冒号调用会将接收者作为首个 Java 参数，因而具有不同的参数数量语义。
  • 普通调用带有自动重载选择；luajava.constructor() 与 luajava.method() 提供对应的精确签名入口，适用于 nil、数值宽度、数组或相近接口类型等场景。

1. 绑定类与创建实例

-- 绑定 Java 类
local File = luajava.bindClass "java.io.File"
local f = File("/sdcard/test.txt")

-- 创建实例
local list = luajava.newInstance("java.util.ArrayList")

-- import 语法（LuaJ++）
import "android.widget.TextView"
import "java.util.*", "java.io.*"
import str "java.lang.String"  -- 别名

local tv = TextView(activity)

2. 表与数组转换

local ArrayList = luajava.bindClass("java.util.ArrayList")
local sourceList = ArrayList()
sourceList.add("one")
sourceList.add("two")

-- Java 集合 / 数组转 Lua 表
local luaTable = luajava.astable(sourceList)
-- astable 的可读别名；默认转换第一层，true 表示递归转换嵌套集合
local copied = luajava.toTable(sourceList)

-- Lua 数组表转 Java 集合，读取下标 1 到 #table
local javaList = luajava.toList({"one", "two"})
local javaSet = luajava.toSet({"one", "two", "one"})

-- Lua 表的全部 entry 转保持当前遍历顺序的 Java LinkedHashMap
local javaMap = luajava.toMap({name = "Lua", version = 1})
print(javaList[0], javaMap["name"])

-- 创建 Java 数组
local a = int[10]
local b = int{1, 2, 3}
local c = Integer[10]

-- 数组长度与下标
print(#a)
print(a[0])      -- Java 数组下标从 0 开始
print(b[2])      -- 取得 int{1, 2, 3} 的第三项

-- Map 和任意 Java Collection（包括 Set）也支持 #
print(#javaSet)

3. Java 数组

写法结果
String[5]长度为 5 的 String[]
int{1, 2, 3}由 Lua table 的数组部分转换而来的 int[]
String.array({"one", "two"})由 Lua table 转换而来的 String[]
array[0]Java 数组的第一个元素
#array / array.lengthJava 数组长度
array.class数组对应的 Java Class，例如 String[].class

类型[n] 中的数值索引由类包装识别为数组长度，并创建以该类型为组件的 Java 数组；table 形式读取 Lua table 的 1..#table 后写入 Java 数组的 0..length - 1。

4. 类成员：array / new / class / override

local String = luajava.bindClass("java.lang.String")

local values = String.array({"one", "two"}) -- 创建 String[]
print(String.new)       -- 构造器
print(String.class)     -- 对应的 Java Class 包装
print(String.override)  -- 覆盖方法入口（见下文）

类型[n] 创建长度为 n 的数组；类型.array(table) 将 Lua table 转为该组件类型的数组。

5. 构造实例与接口实现

local ArrayList = luajava.bindClass("java.util.ArrayList")
local HashMap = luajava.bindClass("java.util.HashMap")
local Runnable = luajava.bindClass("java.lang.Runnable")

-- 直接 () 构造
local b = ArrayList()
local m = HashMap()

-- 接口表实现
local r1 = Runnable {
  run = function()
    print("run")
  end
}

-- 单方法接口可直接传函数
local r2 = Runnable(function()
  print("run once")
end)

抽象类或普通类的覆写由下一节的 类型.override { ... } 提供；luajava.createProxy() 提供显式的接口代理形式。

6. createProxy 代理

-- 字符串接口名 + 实现表
local runnable = luajava.createProxy("java.lang.Runnable", {
  run = function()
    print("running")
  end
})

-- 单方法接口可直接传函数
local runnable2 = luajava.createProxy("java.lang.Runnable", function()
  print("running")
end)

-- 已绑定的 Class
local Runnable = luajava.bindClass("java.lang.Runnable")
local runnable3 = luajava.createProxy(Runnable, function()
  print("running")
end)

-- 多接口：最后一个参数为表或函数；按全部接口查找方法
local Map = luajava.bindClass("java.util.Map")
local Closeable = luajava.bindClass("java.io.Closeable")
local proxy = luajava.createProxy(
  Map,
  Closeable,
  {
    get = function(key)
      return key
    end,
    close = function()
      print("closed")
    end
  }
)

未显式实现 equals / hashCode / toString 时，使用 Java 默认对象语义，避免作为 Map 键时匹配失败。

7. override 覆盖方法

override 生成增强子类，只覆盖表中提供的方法。覆盖方法的第一个参数是 superCall，调用可执行父类原方法。

local ArrayList = luajava.bindClass("java.util.ArrayList")

local list = ArrayList.override {
  add = function(superCall, value)
    print("add:", value)
    return superCall(value)
  end
}()

-- 简写：类后直接跟实现表再构造
list = ArrayList {
  add = function(s, a)
  end
}

-- 抽象类 / 普通类
local FileObserver = luajava.bindClass("android.os.FileObserver")
local path = activity.getLuaDir()
local MyObserver = FileObserver.override {
  onEvent = function(superCall, event, path)
    print(event, path)
  end
}
local observer = MyObserver(path)

未在表中提供的方法保持 Java 原有行为。superCall(...) 会按 Java 签名转换参数。

8. 属性与 getter/setter 语法糖

local TextView = luajava.bindClass("android.widget.TextView")
local textView = TextView(activity)

-- set/get 可写成属性
textView.setText("")
-- 等价
textView.text = ""

local text = textView.getText()
-- 等价
text = textView.text

-- isXxx 简写
textView.isActivated()
-- 可写作
textView.Activated

-- 批量设置属性
local Button = luajava.bindClass("android.widget.Button")
Button(activity) {
  text = "test",
  enabled = false
}

9. 监听器与函数式接口

local View = luajava.bindClass("android.view.View")
local Button = luajava.bindClass("android.widget.Button")
local button = Button(activity)

-- 完整写法
button.setOnClickListener(View.OnClickListener {
  onClick = function(v)
    print(v)
  end
})

-- 接口类型由参数位置确定
button.setOnClickListener({
  onClick = function(v)
    print(v)
  end
})

-- 单方法接口可直接传函数
button.setOnClickListener(function(v)
  print(v)
end)

-- 属性式
button.onClick = function(v)
  print(v)
end

10. Kotlin 类

Kotlin 的 object 与 companion object 在 JVM 上分别会生成 INSTANCE 与 Companion 字段。使用专用函数可避免 Lua 代码依赖这些生成字段名。

-- Kotlin object
local LuaFileUtil = luajava.kotlinObject("com.nekolaska.io.LuaFileUtil")
LuaFileUtil.writeOrCreate(path, content)

-- Kotlin companion object
local Tool = luajava.kotlinCompanion("com.example.Tool")
Tool.run()

-- companion 内标注 @JvmStatic 的方法可直接通过类调用
local ToolClass = luajava.bindClass("com.example.Tool")
ToolClass.runStatic()

Java 和 Kotlin 成员均使用点调用 object.method(...)。Kotlin 默认参数不会自动生成 Java 重载；@JvmOverloads 会生成可从 Lua 调用的重载，而未生成重载的方法以完整 Java 参数签名出现。

11. LuaJ++ 点号字符串索引

local t = {}

-- 索引时，点号后可直接写字符串
t."key with spaces" = 123
t."end" = "keyword is also allowed"
print(t."key with spaces", t."end")

-- 等价的标准 Lua 写法
print(t["key with spaces"], t["end"])

13. 指定重载、数组类型与迭代

普通调用带有自动重载选择。精确签名形式对应某一个公开构造器或方法，可表达 nil、数值、数组与相近接口类型之间的明确选择。

-- parameterTypes 是类型 array；元素可写类名、primitive 名称、Java Class 或 bindClass 的结果
local constructor = luajava.constructor("java.lang.StringBuilder", {"int"})
local builder = constructor(32)

local String = luajava.bindClass("java.lang.String")

-- 返回已绑定到实例的精确方法
local append = luajava.method(builder, "append", {String})
append("Lua")

-- class / 类名 target 对应 static 方法
local valueOf = luajava.method(String, "valueOf", {"int"})
print(valueOf(42))

-- 数组参数的类名形式
local join = luajava.method(String, "join", {"java.lang.CharSequence", "java.lang.CharSequence[]"})

-- 数组实例的 .class 对应数组类型，例如 String[]
local StringArray = String.array({}).class
local Intent = luajava.bindClass("android.content.Intent")
local intent = Intent()
local putExtra = luajava.method(intent, "putExtra", {String, StringArray})
putExtra("names", String.array({"one", "two"}))

-- 独立 iterator：数组、Map、Iterable、Iterator 与 Kotlin Sequence
for index, value in luajava.iterate(javaSet) do
  print(index, value) -- index 从 0 开始
end
for key, value in luajava.iterate(javaMap) do
  print(key, value)
end

luajava.method(target, name, parameterTypes) 返回已绑定方法；target 为实例时对应实例方法，target 为类或类名时对应 static 方法。iterate() 在调用时取得 Java iterator，其集合修改可见性与 userdata 的 pairs() / next() 不同。
