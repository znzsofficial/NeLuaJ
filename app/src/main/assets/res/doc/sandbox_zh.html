AI Lua 沙盒

AI 助手调用“运行 Lua 代码”时，代码会在独立的受限 Lua 环境中执行。它用于验证小型、纯 Lua 的计算或字符串处理，不是工程脚本、Activity 脚本或模块的运行方式。

适合做什么

  • 验证 Lua 语法和小段算法。
  • 测试 table、string、math、utf8、协程和 bit32 的纯 Lua 逻辑。
  • 验证 JSON、Base64、Hex、URL 编解码和 SHA-256 摘要。
  • 在明确批准精确主机名后测试公网 HTTPS API。
  • 通过 print(...) 或 chunk 返回值查看计算结果。

可用环境

沙盒提供基础 Lua 函数，以及 coroutine、string、table、math、utf8 和 bit32。

local total = 0
for i = 1, 10 do
  total = total + i
end
print(total) -- 55

安全工具

  • json.encode(value) / json.decode(text)：JSON 编解码；json.null 表示 null，json.array() 可创建或标记空数组。
  • codec.base64_encode / base64_decode：Base64 编解码。
  • codec.hex_encode / hex_decode：Hex 编解码。
  • codec.url_encode / url_decode：UTF-8 URL 表单编码。
  • hash.sha256(text)：返回小写十六进制 SHA-256。
  • inspect(value)：稳定、带循环保护的 table 展示。
  • assert_equal(actual, expected, message)：递归比较值，失败时显示差异。
  • http.request(url, options)：受限同步 HTTPS 请求；精确主机名还必须写入工具的 network_hosts 参数并由用户批准。
local value = json.decode('{"items":[1,2,3]}')
assert_equal(value.items, {1, 2, 3})
return hash.sha256(json.encode(value))

受限 HTTPS

local response = http.request("https://api.example.com/items", {
  method = "POST",
  headers = { ["Content-Type"] = "application/json" },
  body = json.encode({ query = "Lua" }),
  timeout = 4000,
})
assert_equal(response.status, 200)
return json.decode(response.body)

对应的 run_lua 调用必须包含 network_hosts = {"api.example.com"}。授权只匹配精确主机：批准 example.com 不会同时批准它的子域名。

响应 table 包含 ok、status、message、url、headers、保留重复响应头数组的 header_values，以及二进制安全的 body。

不可用能力

沙盒刻意不提供 Java、Android、文件、不受限网络或进程入口。以下名称不可用：

luajava  import  require  package  debug
io  os  dofile  loadfile  collectgarbage

因此不能在沙盒中访问 activity、调用 Android API、读取工程文件、加载模块、打开任意 socket 或执行 shell 命令。网络仅限 http.request 和用户批准的公网 HTTPS 主机。需要更完整能力时，应修改并在工程正常运行环境中测试相应 Lua 文件。

输出与限制

  • 代码以 UTF-8 计最多 128 KiB。
  • print、chunk 返回值和运行错误会返回给 AI；输出最多 64 KiB，超出部分会标记为截断。
  • JSON、编码和摘要工具的单次输入或结果最多 1 MiB；JSON 最多 10,000 个节点、嵌套 64 层。
  • HTTP 仅允许 HTTPS 443 端口；每次最多批准 8 个精确主机、发起 4 个请求。重定向、代理、URL 凭据、IP 字面量、localhost、私网/链路本地地址和非公网 DNS 结果都会被拒绝。
  • HTTP 请求体最多 256 KiB，响应体最多 512 KiB，每个请求超时限制为 1–6 秒；不会自动附加 Cookie 或应用凭据。
  • 执行时间受限。超时时该次运行失败，AI 应改用更小的输入或更高效的算法。
  • 无限循环或阻塞代码不会继续占用应用主进程；超时后沙盒执行进程会被结束。

常见问题

为什么 require 或 luajava 是 nil？

这是沙盒限制，目的是让 AI 执行的临时代码不能访问工程、设备或 Java bridge。将需要验证的纯函数提取为独立代码测试，或在工程环境中运行。

为什么没有输出？

print 和 Lua chunk 的返回值都会显示。函数内部的普通返回值不会自动显示，需要从 chunk 返回或显式 print(value)。

为什么运行超时？

检查是否有无限循环、递归没有终止条件，或输入规模过大。把任务拆小，并避免在沙盒中进行大规模枚举。
