welcome.lua splash screen

While building an APK, the packager reads welcome.lua from the project root and generates the splash window background, welcome.xml. Without this file, the splash stays the base package's plain background and centered icon.png.

The splash is shown before assets are extracted, so it cannot be a Lua layout and cannot change at runtime. It affects only the packaged app, not the IDE's own launch screen.

The packager runs the file in a Lua environment without files, processes, or a Java bridge, then uses the returned table. string, table, and math may compute fields. io, os, require, and loadfile are not available.

Fields

  • background: #RRGGBB or #AARRGGBB. Defaults to ?colorSurface.
  • icon: image file name in the project root. Defaults to icon.png. If that file is absent, the packaged app keeps the base icon. false hides the icon.
  • icon_size: icon edge length in dp only, such as 160dp.
  • gravity: icon position, such as center or center|bottom.
  • image: full-page image. When set, it fills the splash and icon is ignored.
  • text: up to 80 characters and 6 lines. The packager draws it with the system font into an image, because a window background cannot contain a text view. The size is fixed at 4x density and does not follow the packager phone's font scale.
  • text_size: for example 24sp. Defaults to 24sp.
  • text_color: #RRGGBB or #AARRGGBB. Defaults to white.
  • text_gravity: text position. Defaults to center|bottom when an icon or full-page image is also present.

Images must be in the project root, with a png, webp, jpg, or jpeg extension. The name without its extension must be a lowercase resource name, such as welcome.png. Paths are not accepted. At most 4 custom images and 4 text layers are supported. Install the NeLuaJ+ build that contains these reserved drawables before packaging.

Examples

return {
  background = "#121212",
  icon = "icon.png",
  icon_size = "160dp",
  gravity = "center",
}

return {
  background = "#FF101418",
  image = "welcome.png",
}

Layers

For a gradient, a circle, or several images, use a layers array instead of the fields above. Each layer has one kind of content: a solid color, a gradient, an icon, or an image.

local color = string.format("#%06X", 0x112233)
return {
  layers = {
    { color = color },
    {
      shape = "oval",
      gradient_start = "#00112233",
      gradient_end = "#FF112233",
      gradient_angle = "90",
      size = "240dp",
    },
    { icon = "icon.png", size = "72dp", gravity = "center|bottom", inset = "24dp" },
  },
}

A layer may also set corners, text, text_size, and text_color. Text layers are drawn into images too. A gradient angle must be a multiple of 45. layers cannot be combined with the top-level background, icon, image, or text fields.

Limits

  • The generated drawable contains only layer-list, item, bitmap, shape, solid, and color.
  • Text, buttons, and arbitrary layouts are not available.
  • An unknown field, bad color, pixel unit, or missing image fails that build.
