# 首页与编辑器交接验收

本清单覆盖入口首页（项目、会话、帮助、设置）与编辑器工作台之间的任务闭环。它是设备验收配方，不表示这些场景已经实机通过。维护命令与各层证明范围见 [MAINTENANCE.md](./MAINTENANCE.md)。

## 当前实现边界

- 首页壳使用有稳定页面标识的可重建 Fragment，按实际窗口宽度选择底栏/导航轨；滚动恢复等待页面数据就绪。桌面策略/接线测试不替代 FragmentManager 的设备恢复测试。
- 编辑器离开失败提供重试、取消和二次确认放弃；没有自动草稿或通用另存副本能力。未保存正文仍在内存，进程被回收不能保证恢复。
- “打开工程目录”直接使用有效目录，不声称支持压缩包导入或复制导入；不覆盖原工程。
- 工程改名保留迁移日志、原状态副本与 Agent 路径别名，不声称跨文件事务。发生部分失败时应在首页显式重试，不手工删除源数据，也不在后台列表扫描中自动恢复改名。仍被编辑器引用的工程应先关闭再改名，不能仅更新标签显示就认为旧路径闭包已重绑；当前跨 Activity 检查采用保守阻止策略，不保证覆盖所有并发多窗口实例或跨进程编辑者。
- Agent 根目录别名保留原文件；文件变更撤销历史中的绝对路径/旧 scope 不自动改写，不能承诺改名后继续复用旧 undo 历史。

## 数据安全与失败注入

- 旧会话迁移分别模拟记录写入失败、索引写入失败：旧源不得清除，重试/重启后记录不得缺失；完全成功后才可清源。
- 工程改名分别模拟目录操作失败和关联状态写入失败：错误必须可见，旧数据不得静默删除；确认工作区标签、光标、会话与最近打开入口仍能关联正确工程。
- 编辑器保存分别返回 true、same、false、nil 和抛异常：只有成功或用户明确确认放弃后才能离开。菜单退出、返回键及提示动作不得绕过同一保护。
- 待办跳转执行失败或被新请求替换：不得错误确认消费另一请求；失败可重试或明确取消。

## 首次使用与入口闭环

- 首页新建工程：分别勾选/取消“创建后打开”。勾选时进入新工程 main.lua；取消时留在首页且列表出现工程。
- 编辑器内新建工程：同样覆盖两种选择，不破坏现有工作区恢复。
- 无文件权限、取消申请、拒绝后重试、手动在设置授权后返回：不得用“没有工程”替代授权或读取错误，页内应有可执行恢复入口。
- 工程根不存在、根路径实际为文件、读取异常、真正空目录及搜索无结果：分别核对状态文案和操作。
- 零会话、有工程但未配置模型、零工程、有历史会话但工程已删除：新建/打开入口应有明确结果，不能指向不存在的按钮或静默失败。
- 打开已有目录或导入工程时：测试取消、无效结构、重名目标；不得静默覆盖现有工程。不支持的导入格式必须明确说明。

## 列表、搜索与后台归属

- 用较多工程、长应用名/包名和较大的工程图标刷新：首页首帧、滚动和搜索分别测量，不以编译或使用线程替代性能测量。
- 检查项目/会话行的 12dp 实际间距、最近卡片的固定宽度与间隔。正常/加载/搜索无结果时不显示重试，权限/读取失败有恢复入口；会话页只显示一个新建按钮。
- 最近打开按实际打开记录排序；在已有文件中编辑正文不应被错误解释为目录最近打开时间。
- 搜索覆盖工程目录名、应用名、包名；清除恢复原列表。快速输入和交错刷新，旧结果不得覆盖新查询。
- 多个大正文会话：列表读取应只取元数据；点击单个会话时才加载正文。
- 刷新后立即切页、后台、关闭首页或重建：过期后台结果不得访问已释放视图或覆盖新页面。

## 性能采样（仍需设备）

- 固定设备、主题、字体、窗口尺寸及同一批项目/会话，分别记录冷启动、编辑器返回首页、切换四页、快速搜索、连续滚动；不要混用冷/热缓存结果。
- 对改动前后各重复相同操作，记录帧时间分位数/掉帧数、首次可操作时间和峰值内存。可用系统帧统计或 Perfetto；JVM/宿主替身中的少量耗时不作为手机上的提速倍数。
- 大量索引记录下，确认首次显示与单条更新；不变刷新应不重绑定全部行、不重建最近卡片、不让 loading 文案撑开头部。删除、重排、搜索清除后点击仍需指向正确工程/会话。
- 帮助页改为回收列表后，检查分类标题、卡片间距、点击与滚动恢复；同时观察 ViewPager 预加载相邻页和设置页首次构建的开销。
- 若冷启动仍卡，进一步采样 bootstrap 的类名预加载、资源反射、图标解码与 GC；这些只是待定位的候选点，不能凭源码直接断言是当前设备瓶颈。

## Android 设备矩阵

- 手机竖屏/横屏、平板、分屏从宽到窄再变宽；保持选中目的地，窄窗编辑器能临时回退抽屉而不改写平板偏好。
- 主题色修改后 recreate、旋转及系统回收恢复：四页不空白，当前 tab 与导航选中项一致，滚动位置合理恢复。
- TalkBack 顺序滑动和触摸探索：每个设置开关一次焦点即可知道名称与状态，切换后状态播报正确。
- 功能栏自定义：上下移动控件触控范围、名称、复选框关联及重建后焦点；外接键盘也可连续操作。
- 系统字体放大与显示尺寸放大：输入框、运行状态标签和长工程元信息不裁切关键内容。
- 横屏或小高度分屏中，上滑应收起项目/会话头部，下滑可重新找到主操作；不能因最近工程/错误文案变高而完全挤没列表。测试中英文、1.3×/2×字体和键盘显示后的状态。
- 三键和手势返回：首页各 tab 提示（若有）绑定可见宿主；编辑器先关闭抽屉/搜索，再执行安全离开。
- 浅/深主题、项目图标与主题资源、键盘弹出时确认按钮可达；未启用 edge-to-edge 时不盲目叠加系统栏 padding。
